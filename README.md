## File Structure

- `paxosbus/cmd/`: replica and client entry points.
- `paxosbus/docs/`: experiment setup and usage instructions.
- `paxosbus/internal/`: protocol, configuration, wire messages, and logging.
- `paxosbus/scripts/`: single-machine and multi-machine runners.
- `paxosbus/tla/`: TLA+ specifications.
